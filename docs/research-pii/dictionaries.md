# Словари русского языка (легальные открытые)

Принцип: только открытые лицензии (MIT/CC0/CC-BY/OpenCorpora). Гигантские наборы не качаем — фиксируем источник и формат.

| Словарь | Источник | Размер (порядок) | Лицензия | Формат | Брать? |
|---|---|---|---|---|---|
| Имена/фамилии/отчества (OpenCorpora + Natasha data) | opencorpora.org, github natasha/* | ~100k форм | CC-BY-SA / MIT (проверить файл) | txt/csv, lemma+forms | да, леммы + топ-N частотных |
| Страны + гражданства/национальности | ISO 3166 + открытые списки (Wikipedia CC-BY-SA — только факты, не текст) | ~250 | факты не охраняются; список — свой | txt | да |
| Регионы РФ (85 субъектов) | Конституция/ФНС (официальные перечни) | ~85 | официальные документы — public domain | txt | да |
| Города/населённые пункты (сокращённый топ) | ФИАС (nalog.ru, открытый) / OSM (ODbL — осторожно!) | ФИАС — GB; топ-10k — KB | ФИАС — открытая лицензия ФНС; OSM — ODbL (share-alike!) | csv/xml | топ-N из ФИАС, OSM — только с юристом |
| Улицы/типы улиц (`ул.`, `пр.`, `пер.`, `ш.` ...) | свой список по ФИАС-документации | ~50 типов | свой | txt | да |
| Госорганы (УФМС/ОМВД/ГУВМ/ОВИР шаблоны) | официальные названия ведомств | ~100 шаблонов | public domain | regex-шаблоны | да, как паттерны |
| Типы документов-маркеры | свой список (паспорт, свидетельство, удостоверение...) | ~50 | свой | txt | да |

Предупреждения:
- ФИО-словари дают recall, но и FP (Пушкин — тоже в словаре). Всегда пара «словарь + контекст/роль».
- OSM под ODbL — copyleft на базу; для коммерческого DetoxProxy брать только факты/топонимы из ФИАС или с разрешения.
- OpenCorpora — CC-BY-SA: производный словарь внутри сервиса — проверить с юристом, хранить как внешний артефакт, не вшивать без атрибуции.
