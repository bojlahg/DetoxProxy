# Адресные сокращения (приказ Минфина № 171н, ФИАС SOCRBASE) и почтовые индексы — сводка 22.09.2026

Официальные сокращения ставят точку (`ул.`, `пер.`, `д.`, `кв.`), кроме стяжений (`р-н`, `б-р`, `пр-кт`, `кв-л`, `ст-ца`, `пр-д`) и форм на ту же букву (`край`, `аул`, `парк`, `сад`, `км`, `цех`, `офис`). В текстах сосуществуют старые формы без точки (`ул`, `пер`, `проезд`, `аллея`, `мкр`, `тер`, `д`, `с`, `п`, `г`, `пгт`, `рп`) и разговорные (`пр-т`, `пр.`, `просп.`, `корп.`, `оф.`, `пом.`, `эт.`, `кв-ра`, `дер.`, `гор.`). Детектор принимает все три группы.

## Ключевые сокращения по уровням
- Регион: респ., край, обл., г.ф.з., а.обл., а.окр.; р-н, м.р-н, г.о., м.о., с.п., г.п.
- Населённый пункт: г., нп., пгт., рп., дп., кп., п., с., д. (деревня), сл., ст., ст-ца, х., аул, м-ко.
- Планировочная структура: кв-л, мкр., тер., ж/р, п/р, наб., парк, сад, сквер, тер. СНТ/ГСК/ТСЖ.
- Улично-дорожная сеть: ул., пр-кт, пер., наб., ш., б-р, пл., пр-д, туп., ал., лн., дор., тракт, км, с-к, к-цо, ззд., взд., пр-к, пр-ка, проул., рзд., мгстр.
- Объект адресации: д. (дом), влд., двлд., зд., соор., стр., к. (корпус), литера, г-ж, з/у, м/м, ОНС.
- Помещение: кв., ком., офис, помещ., пав., скл., цех, раб.уч., торг.зал.

## Конфликты сокращений (для детектора)
| Сокр. | Значения | Различение |
|---|---|---|
| д. | дом / деревня | перед числом — дом (`д. 5`, `д. 5А`, `д. 5/2`); перед словом с заглавной — деревня; после элемента УДС — почти всегда дом |
| г. | город / год / гражданин | перед именем с заглавной + далее адресные элементы — город; после 4-значного числа — год; перед ФИО с инициалами — гражданин |
| п. | посёлок / пункт | перед именем — посёлок; перед числом — пункт |
| с. | село / страница | перед именем — село |
| ст. | станция / станица / статья | перед именем — станция; перед числом — статья |
| к. | корпус / копейка | после номера дома — корпус |
| стр. | строение / страница | после `д. N` — строение |
| пр. | проспект / проезд (разговорно) | элемент УДС без уточнения |
| пл. | площадь (УДС) / площадь м² | перед именем — УДС |

## Почтовые индексы
6 цифр: первые 3 — субъект РФ, последние 3 — отделение. Диапазоны субъектов: 101–199 (Москва, МО, СЗФО), 214–299 (Смоленск…Крым/Севастополь 295–299, новые территории 269–294), 300–399, 400–468 (в т.ч. Байконур 468), 600–694. Служебные: 500xxx, 800xxx, 9xxxxx (постаматы). Нет 0xxxxx и 7xxxxx.
- Строгий регекс (жилые адреса): `\b[1-46][0-9]{5}\b`
- Полный: `\b(?:[1-46][0-9]{5}|500[0-9]{3}|800[0-9]{3}|9[0-9]{5})\b`
- Индекс считать частью адреса только при соседстве с адресными элементами (иначе ложные срабатывания на суммах и номерах договоров).
