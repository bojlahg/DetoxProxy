# Context detection: keywords, suppressors, scoring

Основа: Presidio `LemmaContextAwareEnhancer` (boost +0.35 в окне) + анализ примеров RMR benchmark + brikkoAI context-списки.

## 1. Positive keywords (lowercase, леммы)

```
PASSPORT: паспорт, паспортные данные, серия, номер паспорта, выдан, код подразделения
BIRTH_DATE: дата рождения, родился, родилась, г.р., год рождения, д.р.
BIRTH_PLACE: место рождения, родился в, уроженец, уроженка
CITIZENSHIP: гражданство, гражданин, гражданка, подданство
ISSUE_AUTHORITY: выдан, орган выдачи, кем выдан, уфмс, овд, омвд, гувм
DIVISION_CODE: код подразделения
ISSUE_DATE: дата выдачи, выдан, действителен
DRIVER_LICENSE: водительское удостоверение, права, в/у, водительские права, удостоверение водителя
ADDRESS: адрес, проживает, зарегистрирован, ул, улица, дом, корпус, квартира, индекс
PHONE: телефон, тел, моб, сотовый, позвонить, номер телефона
INN: инн, идентификационный номер налогоплательщика, налогоплательщик
CARD: карта, номер карты, банковская карта, card, кредитная карта
CARDHOLDER: держатель, владелец карты, cardholder, имя держателя
CVV: cvv, cvc, код безопасности, три цифры
PIN: pin, пин, пин-код
EMAIL: email, e-mail, почта, электронная почта
```

Регистр игнорировать (`ИНН/инн/Инн`). Для дат/телефонов/адресов — максимально разнообразные формы (см. ТЗ §14).

## 2. Negative / suppressor keywords (гасят score или запрещают)

```
FAMOUS: пушкин, толстой, гагарин, родился в 1799, исторический деятель, персонаж, фильм
ORG_ADDRESS: отделение банка, филиал, юридический адрес компании, адрес кремля, офис банка
DOC_TALK: pin-код состоит из, cvv находится, инн содержит, пример, документация, образец
META: номер заявки, номер заказа, номер сборки, код ошибки, build, parser
```

Правило: если в окне ±64 символов есть suppressor И нет person-маркера (ФИО/«клиент»/«паспорт») → score *= 0.1 или дроп.

## 3. Дистанция и scoring

- Окно: ±64–128 символов (Presidio default ~10 слов; для русского с длинными конструкциями берём шире).
- Decay: `boost = base * 1/(1 + dist/32)`, где dist — символы между краем спана и ключевым словом.
- Направление: префиксный контекст (ключевое слово ДО значения) весомее постфиксного (×1.0 vs ×0.6) — проверено на RMR-примерах (`паспорт серии 9815...`, `ИНН 500100732259`).
- Порог: validated (КС ✓) — контекст не обязателен; невалидированные короткие (CVV/PIN/код) — требовать контекст строго (иначе не эмитить).
- Лемматизация для русского: pymorphy2/slovnet-леммы в research-фазе; в Rust — нижний регистр + словарь словоформ (без тяжёлой морфологии) + Aho-Corasick.
