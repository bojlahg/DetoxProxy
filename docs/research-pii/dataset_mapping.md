# Mapping: redmadrobot labels → Alfa

Источник разметки: `redmadrobot-rnd/pii_benchmark` (MIT, test.csv, BIO на токенах). Дата доступа 2026-09-22.

| RMR label | Alfa категория | Комментарий |
|---|---|---|
| `FIRST_NAME`, `MIDDLE_NAME`, `LAST_NAME` | **ФИО** | Склеивать соседние `LAST+FIRST+MIDDLE` в один span. Одиночное имя без контекста — низкий score |
| `EMAIL` | Email | 1:1 |
| `PHONE` | Телефон | 1:1 (включая `8-...`, `+7...`, короткие `861-...` с контекстом) |
| `INN` | ИНН | 1:1 |
| `PASSPORT` | Паспорт серия+номер | В RMR серия и номер иногда два спана — склеивать; в upstream pii-guard это data-only спаны (`framework/spans.py`) |
| `SNILS` | СНИЛС (расширение Alfa; тот же класс КС-документов) | 1:1 (gold 223 в benchmark, 924 в train) |
| `OMS` | Полис ОМС (расширение) | 1:1 (gold 170/742); в конфликте CARD-vs-OMS решает дистанция 100/220 |
| `CREDIT_CARD` | Номер банковской карты | 1:1 |
| `DRIVER_LICENSE` | Водительское удостоверение | 1:1 |
| `BIRTH_CERTIFICATE` | — (расширение, не в Alfa-списке) | Оставить как доп. детектор; полезен для снижения FP дат |
| `OMS` | — (расширение) | Полис ОМС; не в Alfa, но тот же класс «документ с цифрами» |
| `MILITARY_ID` | — (расширение) | Военный билет |
| `IP_ADDRESS`, `URL` | — (не ПД, но детектить для полноты логов) | Не маппить в Alfa, но не путать с ПД |
| `COUNTRY`, `REGION`, `CITY`, `DISTRICT`, `STREET`, `HOUSE`, `APARTMENT`, `POSTAL_CODE` | **Адрес** (склейка) | Правило: последовательность адресных компонентов с дистанцией ≤ N токенов (адресные маркеры `ул.`, `д.`, `г.`, `дом`, `офис`) → единый `ADDRESS` span. Одиночный `CITY`/`COUNTRY` без адресного контекста — НЕ адрес (hard negative: «Сравни Люксембург и Боливия») |
| `BIRTH_DATE` (если появится в train) | Дата рождения | В benchmark-семпле не встречен отдельным тегом — закрываем synthetic |
| *нет метки* | Дата выдачи, Место рождения, Гражданство, Орган выдачи, Код подразделения, CVV, PIN, Держатель карты | Нет покрытия — только synthetic corpus |

## Адрес: правило склейки (рекомендация)

```
 components = [COUNTRY?, REGION?, CITY?, DISTRICT?, STREET, HOUSE, APARTMENT?, POSTAL_CODE?]
 если в окне W токенов есть ≥2 компонентов ИЛИ 1 компонент + адресный маркер (ул|д|г|дом|корп|кв|индекс)
   → ADDRESS span = [min.start, max.end]
 иначе → не адрес (O)
 suppressors: «отделение банка», «юридический адрес компании», «Кремль» без персоны → не адрес физлица
```

Проверено на примерах benchmark: `УЛ. РОКОССОВСКОГО, дом 10, офис 15, ВОЛЬСК` → STREET+HOUSE+CITY = адрес; `Курганской области` один REGION без маркеров — в benchmark помечен REGION, но для Alfa это НЕ адрес без персоны/маркера (кандидат в hard negative).
