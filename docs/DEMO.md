# Сценарий демо (5 минут)

Под критерии жюри: полнота типов, маска необратима снаружи и обратима внутри, ловушки, гибкость настройки, лог и метрики. Все команды — на рабочем стенде или локально (`cargo run --release -- --config config.yaml`).

```bash
export U=http://93.183.93.44:8080      # или http://localhost:8080
p() { curl -s $U/process -H 'Content-Type: application/json' ${3:+-H "X-System-Id: $3"} \
        -d "{\"payload\": \"$1\", \"payload_id\": \"$2\"}"; echo; }
```

## 0. Страница /demo (вместо curl)

Всё ниже можно показать на `$U/demo`: в каждом блоке кнопки примеров («Все 17 типов», «Ловушки», «Регистр и форматы», «PIN: один и с картой»; «Ответ с падежами», «Все падежи», «Искажённые токены»; «Два человека», «Город и гражданство», «Адрес доставки»). Третий блок показывает системный промпт, запрос с метками `<<FIO_1:дат>>` и таблицу склонений. Вверху — живые RPS, TPS и p99 из `/stats`.

## 1. Все типы в одном письме (60 с)

Говорим: «Оператор пересылает в LLM обращение клиента целиком, как есть».

```bash
p "Клиент Сидоров Пётр Иванович, 12.03.1985 г.р., место рождения г. Казань, гражданство РФ. Паспорт 4509 123456, выдан ОУФМС России по г. Москве 15.06.2015, код подразделения 770-001. ИНН 500100732259, СНИЛС 112-233-445 95, ВУ 77 12 345678. Проживает: г. Казань, ул. Баумана, д. 14, кв. 8. Тел. +7 912 345-67-89, email petr.sidorov@mail.ru. Карта 4276 5500 1122 3347, держатель PETR SIDOROV, CVV 317, PIN 4821." demo-1
```

Показываем: 18 значений → 18 токенов, каждое своим типом, в тексте не осталось ни одной цифры клиента. Время ответа — в логе, меньше миллисекунды.

## 2. Ответ LLM восстанавливается, чужой — нет (40 с)

```bash
p "Уважаемый <<FIO_1>>, карта <<CARD_1>> перевыпущена, новый PIN придёт на <<PHONE_1>>." demo-1
p "Уважаемый <<FIO_1>>, карта <<CARD_1>> перевыпущена." demo-чужой
```

Первый — значения на месте. Второй, с другим `payload_id`, — токены остаются токенами: соответствия изолированы по запросу и по системе.

## 3. Падеж (30 с)

```bash
p "Передайте <<FIO_1:дат>>, что заявка одобрена." demo-1
```

→ «Передайте Сидорову Петру Ивановичу». Модель сама выбирает падеж, прокси склоняет.

## 4. Ловушки (40 с)

```bash
p "Поэт Александр Сергеевич Пушкин родился 6 июня 1799 года." t1
p "Адрес отделения банка: г. Казань, ул. Баумана, д. 3." t2
p "Заполните форму: ФИО, дата рождения, ИНН, PIN и CVV." t3
p "IMEI 356938035643809, горячая линия 8 800 200-00-00, накладная 9876 543210." t4
```

Все четыре — без изменений. Говорим: «лишняя маска портит ответ LLM не меньше, чем пропуск — поэтому 258 похожих, но не персональных строк из нашего набора проходят чистыми».

## 5. Разные системы — разные правила (40 с)

```bash
p "ИНН 500100732259, карта 4276 5500 1122 3347" s1 chatbot
```

→ хеш-токены `<<INN_f5c0b7>>`: стабильны между запросами, кеш промптов LLM не ломается. Затем то же в режиме `pseudonym` — текст остаётся естественным: «Сидоров» → «Черняков», ИНН и карта с верной контрольной суммой (`docs/MASKS.md`).

## 6. Новый тип без пересборки (60 с)

Этот шаг — на локальном запуске: на стенде эндпоинт перезагрузки выключен (не задан токен). Сначала показываем, что госномер не маскируется: в поставке его нет среди 17 типов. Затем дописываем в `data/pii_types.yaml` 10 строк из `docs/JURY.md` (раздел 5) и перезагружаем без рестарта:

```bash
DETOX_ADMIN_TOKEN=secret ./target/release/detox-proxy --config config.yaml &   # до правки
U=http://localhost:8080
p "Госномер А123ВС777 в протоколе" s2          # без изменений
# ... правка data/pii_types.yaml ...
curl -s -X POST $U/admin/reload -H 'X-Admin-Token: secret'
p "Госномер А123ВС777 в протоколе" s3
```

→ `<<PLATE_1>>`. Сервис не перезапускался, запросы в этот момент не прерывались.

## 7. Лог и метрики (30 с)

```bash
curl -s $U/stats                     # RPS, TPS, p50/p99 за минуту
curl -s $U/metrics | grep -E '^pii_(requests_total|entities_total|tokens_total|latency_seconds_count)' | head
```

и одна строка журнала: тип и число сущностей, задержка, статус — **ни одного значения ПД**. Говорим: «сегодня ночью организаторы дали 300 тысяч запросов на 1000 RPS: все 200, p99 — 1 мс».

## Если спросят

- *Почему не нейросеть?* — `docs/LIMITATIONS.md`: правила дают < 1 мс и предсказуемость; NER — второй уровень в плане развития, только для неуверенных случаев.
- *Сколько держит?* — `docs/LOAD.md`: 7700 запросов/с пик на 4 ядрах, 1000 RPS с p99 1 мс.
- *Точность?* — `docs/QUALITY.md`: на чужом, ни разу не виденном наборе HiveTrace — 86% полноты при 99,6% точности.
